買賣超金額怎麼算的？

證交所與櫃買中心的官方個股報表只公布買賣超股數，沒有金額欄位。 這裡的金額 = 買賣超股數 ×「當日成交均價」，均價取自同一交易日的收盤行情， 以成交金額 ÷ 成交股數求得，因此是估算值而非逐筆成交價加總。 與聚財網等來源比對過，方向與量級一致；少數金額很接近的個股，名次可能會有一兩名的落差， 屬於這個估算方法本身的誤差範圍。

資料來源：臺灣證券交易所、證券櫃檯買賣中心、臺灣期貨交易所。個股買賣超金額由官方公布之買賣超股數乘上當日成交均價估算，與券商系統會有些微差異。
