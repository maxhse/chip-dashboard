買賣超金額怎麼算的？

證交所與櫃買中心的官方個股報表只公布買賣超股數，沒有金額欄位。 這裡的金額 = 買賣超股數 ×「當日成交均價」（成交金額 ÷ 成交股數），用同一交易日收盤行情反推出來的估算值， 不是逐筆成交價加總。跟看盤軟體或聚財網比對過，方向與量級一致， 少數金額很接近的個股名次可能會有一兩名的落差，屬於估算方法本身的誤差範圍。

資料來源：臺灣證券交易所、證券櫃檯買賣中心、臺灣期貨交易所。個股買賣超金額由官方公布之買賣超股數乘上當日成交均價估算，與券商系統會有些微差異。
